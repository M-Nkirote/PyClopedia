# <span style="color: #BE5985;">🌸 Data Types & Structures - Overview</span>

In Python, *data types* describe **what kind of value** something is
and *data structures* describe **how data is organized or stored**.

Understanding these is essential because they determine:

* What operations you can perform
* How data behaves
* How Python stores and processes information

---

# <span style="color: #EC7FA9;"> 🧁 What Are Data Types?</span>

A **data type** tells Python *what kind of value you’re working with*.

For example:

* Is it a number?
* Is it text?
* A true/false value?
* A collection of items?

Python automatically recognizes data types (you don’t have to declare them).
This makes the language very beginner-friendly.

---

# <span style="color: #FFB8E0;"> 🍬 Built-in Python Data Types</span>

Below is a quick overview of the most important ones.

---

## **1. Numbers**

Numbers represent numeric values.

Python has three main kinds:

* **int** → whole numbers (e.g., `3`, `100`)
* **float** → decimals (e.g., `3.14`)
* **complex** → numbers with real + imaginary parts (e.g., `2 + 3j`)

---

## **2. Strings (`str`)**

Strings represent text - letters, words, sentences, even emojis.

Example:
`"Hello"`,
`"PyClopedia 💗"`

Strings support slicing, replacing, joining, and formatting.

---

## **3. Booleans (`bool`)**

Booleans represent truth values:

* `True`
* `False`

They often appear in comparisons and conditions.

---

# <span style="color: #EC7FA9;"> 🍡 Python Data Structures </span>

Python offers rich built-in data structures to organize collections of data.

---

## **4. Lists**

Lists are:

* Ordered
* Mutable (can change)
* Allow duplicates

Example:
`["pink", "white", "rose"]`

Perfect for flexible, editable collections.

---

## **5. Tuples**

Tuples are similar to lists but:

* Ordered
* **Immutable** (cannot change after creation)

Example:
`("apple", "banana", "cherry")`

Great for data that should not be modified.

---

## **6. Dictionaries**

Dictionaries store data as **key → value** pairs.

Example:

```python
{
  "first_name": "Fridah",
  "project_name": "PyClopedia"
}
```

They are fast, powerful and widely used.

---

## **7. Sets**

Sets are:

* Unordered
* Unique (no duplicates)
* Fast for checking membership

Example:
`{"a", "b", "c"}`

Useful when you need uniqueness or fast lookup.
